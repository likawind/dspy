# Getting Started with RunLLM

Welcome to RunLLM! This guide will help you set up the application quickly and efficiently. Follow these steps to get started:

## Step 1: Install the Application

Begin by installing the RunLLM application. You can find detailed installation instructions in the [RunLLM Zendesk app documentation](https://github.com/runllm/ApiOverflow/blob/main/src/zendesk-app/runllm/translations/en.json).

## Step 2: Locate Your Assistant ID and API Key

1. **Assistant ID**: Log in to your [RunLLM console](https://app.runllm.com/assistants). You can find your assistant ID in the URL of your console. Enter this ID in the 'RunLLM Assistant ID' field in your application settings.

2. **API Key**: In the same console, click on your account avatar located in the lower-left corner to find your API key. Enter this key in the 'RunLLM API Key' field in your application settings.

## Step 3: Enter Your Credentials

- **RunLLM Assistant ID**: Enter the assistant ID you located in Step 2.
- **RunLLM API Key**: Enter the API key you located in Step 2.

## Step 4: Configure the Server Address

- **For Regular Users**: Use `https://api.runllm.com` as your server address.
- **For Enterprise Customers**: If you have a dedicated RunLLM deployment, enter your custom server address in the 'RunLLM Server Address' field. If you are unsure about your server address, please contact [RunLLM](https://www.runllm.com) for assistance.

## Additional Resources

For more detailed information, please refer to the [RunLLM Zendesk app documentation](https://github.com/runllm/ApiOverflow/blob/main/src/zendesk-app/runllm/translations/en.json). This resource provides comprehensive guidance on using the RunLLM application effectively.

By following these steps, you should be able to set up and start using RunLLM with ease. If you encounter any issues, do not hesitate to reach out to RunLLM support for further assistance.
